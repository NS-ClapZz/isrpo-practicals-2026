# Практическая работа №3 (ИСРПО 12–13)

Учебный проект: REST API для интернет-магазина одежды на платформе ASP.NET Core 8 (.NET 8) с использованием Entity Framework Core и SQLite.

## Содержание

Проект расположен в каталоге [`API-магазин-одежды`](API-магазин-одежды/):

- **Каталог товаров:** публичный список одежды, фильтрация и поиск по названию.
- **Размеры и склад:** учет остатков по размерам (S, M, L и числовые размеры) с автоматическим списанием при покупке.
- **Аутентификация:** регистрация и вход покупателей с хешированием паролей, ролевой доступ (`Customer` и `Manager`) через сессионные cookie.
- **Заказы:** оформление заказов авторизованными пользователями с фиксацией цен и размеров на момент заказа, просмотр истории.
- **Панель менеджера:** изменение статусов заказов (`New`, `Processing`, `Completed`, `Cancelled`), управление остатками и доступностью позиций в каталоге.
- **Тестирование:** коллекция Postman (13 запросов, 22 автоматические проверки) и скриншоты прохождения тестов.

## Требования

- Windows, Linux или macOS;
- .NET 8 SDK или новее;
- Postman (для тестирования API).

## Быстрый старт

1. Откройте терминал в папке проекта:
   ```bash
   cd API-магазин-одежды/ClothesApi
   ```

2. Запустите веб-сервис:
   ```bash
   dotnet run
   ```

Сервер будет доступен по адресу `http://localhost:5000`. При первом запуске автоматически создается база данных `clothes.db` и демонстрационный каталог товаров.

Решение для Visual Studio доступно по пути `API-магазин-одежды/ClothesApi.sln`.

Подробная документация и инструкция по тестированию через Postman находятся в [`API-магазин-одежды/README.md`](API-магазин-одежды/README.md).
